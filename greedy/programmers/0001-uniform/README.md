## 문제 링크

- [체육복](https://school.programmers.co.kr/learn/courses/30/lessons/42862)

## 핵심 아이디어

- 선택 범위가 `i - 1` / `i + 1` 둘 밖에 없음
- `i - 1` 빌릴 수 있으면 빌리는 게 무조건 이득 -> 전체 최적해 - 안 빌리면 다른 학생이 빌릴 수 없음 (선형 탐색 가정할 때)
  => 그리디 알고리즘

## Note

- 투 포인터보다 체육복 수 배열 관리하는 게 더 쉬움
  - 두 리스트 중복 원소 제거가 비효율적이기 때문 (중간 요소 삭제)
- 주어진 번호 (1부터 시작) 그대로 쓰기로 했으면 배열 범위 검사는 `i <= n` 임에 유의
  - `if (i > n) continue`
- 그리디 문제 특징
  - 1차원 선형 구조 - 1 ~ N 번호
  - 인접 요소 상호작용
  - 단방향 진행 시 기회비용 소멸
